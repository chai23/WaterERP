# 後台介面設計檢查

日期：2026-10-16

本輪範圍：管理後台的登入頁、共用導覽、營運總覽，以及頁面載入體驗。以 Awwwards、Webby Awards、FWA 的設計完成度作為方向；不代表獲獎或外部評審認證。

| 面向 | 實作與檢查 |
| --- | --- |
| 排版 | 登入採非對稱雙欄；總覽採一致網格、數字字寬與清楚的標題層級。 |
| 留白 | 統一頁面邊距、卡片間距與分區節奏；手機篩選器不再被舊樣式拉成冗長單欄。 |
| 視覺層級 | 深綠突出營收；待收使用警示色；應收帳款獨立為次層資訊。 |
| 色彩 | 米白、深綠與低彩度輔助色；明暗主題共用設計語言；加深小字以改善對比。 |
| 動效 | 一次性的淡入與水紋入場；支援 prefers-reduced-motion，停用過場與平滑捲動。 |
| 微互動 | 常用入口 hover、按鈕回饋、可見鍵盤焦點、密碼顯示、搜尋空結果與失敗重試。 |
| 響應式 | 檢查 320、390、768、1024、1440、1920px；登入與總覽皆無水平溢出。 |
| 原創性 | 自行繪製 SVG 水滴與水紋，以送水服務的流動性串連登入與總覽；無新增圖像或動畫套件。 |

## 驗證

- `npm run build -w apps/web-admin` 通過 TypeScript 與 Vite 正式建置。
- Playwright／Chrome：登入員編大寫、密碼顯示／隱藏、登入錯誤、管理員建立表單切換及錯誤清除。
- Playwright／Chrome：導覽搜尋、搜尋空結果、側欄收合、手機抽屜與 Escape、區間篩選、明暗模式。
- Playwright／Chrome：摘要與異常中心失敗後重試恢復；瀏覽器未出現未處理的 JavaScript 錯誤。
- 正式版 smoke check：建立訂單、分配訂單、客戶資料、AR 沖帳與稽核頁面可完成按需載入。
- 收合／隱藏導覽不接收鍵盤焦點；手機抽屜有焦點循環與返回；提供跳至主要內容連結。
- 主 JavaScript 檔由本輪按需載入優化前的 826.82 KB 降至約 396 KB；不代表所有分割檔案合計體積。
- `git diff --check` 通過。

## 驗證界線

瀏覽器資料與錯誤狀態使用隔離的 API 測試回應，沒有新增測試登入入口、建立實際管理員、修改真實客戶資料或執行交易。未驗證真實後端帳號登入、資料庫整合、Safari／Firefox 或實機觸控。本輪未重新設計所有業務表單；司機端與 LINE 訂水頁未變更。
