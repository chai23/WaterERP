# 分派狀態：調度工作台

入口：分配訂單 → 分派狀態。左側待派訂單池可搜尋單號、客戶與地址，篩選當日／預約／逾期，全選或逐筆勾選；右側司機卡片可指派所選訂單，或按住訂單的「拖曳指派」把手拖放。確認視窗列出司機、車輛、日期與訂單，取消不寫入。

沿用既有 assignment-queue、by-driver-date、batch-assign API，不需新增後端端點。每次指派後重新讀取訂單池與司機任務。部分失敗會顯示原因；日期切換清空舊任務與選取項目，載入完成前禁止指派。每次讀取最多 500 筆待派單，滿額時明確顯示提示。

資料限制：啟用中的司機不等同即時上線；車型來自車輛描述。剩餘單量與桶數為每日設定上限扣除當日已派任務，包含已完成任務；不是車輛剩餘公斤載重。重量、材積與即時在線狀態尚無來源，畫面明確標示。任務時間軸使用期望時段或既有配送時段，不推算 ETA 或承諾空檔。超出設定額度時提示核對，沿用現有人工派單規則。

## 拉回待派池

司機任務時間軸新增「拉回訂單池」按鈕與「拖回」把手。按住把手拖至左側訂單池，確認後將任務標記 cancelled、訂單恢復 confirmed；原任務保留，記錄 returned_to_pool 事件及操作者，帳務不變。

僅 assigned 且未回報、未核銷、未完成的任務可拉回；已有配送數量確認紀錄亦會拒絕。並行拉回使用鎖定及條件更新避免重複，司機回報更新也檢查原狀態，避免已取消任務被舊請求覆蓋。
