## 19 組帳務驗證

1. 日期曆法有效性。
2. 全部客戶、部分收款、多地址、截止日最後一秒。
3. 舊資料帶正號金額（例如 +1000）。
4. 已付款但未配送的訂單仍列待辦移交。
5. 舊版開帳紀錄阻擋重複承接。
6. 新系統已有交易時禁止期初覆寫。
7. 未核對、負預收金額及竄改客戶清單被拒絕。
8. 截止日後收款（即使訂單目前已付款）阻擋錯誤歷史餘額。
9. 草稿版本衝突。
10. 來源或新系統資料變動後拒絕過時快照。
11. 中途資料庫失敗，所有 AR、流水與狀態全部回復。
12. 同時／重複啟用只建立一次應收。
13. 啟用時間時區、舊單與 AR 對照保存。
14. 金額預收、預付桶、多地址空桶、啟用後鎖定。
15. 舊版直接開帳／覆寫同步 API 停用。
16. 期初月結及舊待結項目可在月結畫面查到。
17. 同時月結只認領一次，按相符稅額口徑分批。
18. 含稅月結發票及 AR 金額正確，待結清單清除。
19. 實際收款 API 可沖清承接的期初應收。
