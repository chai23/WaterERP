# 客戶主檔同步

管理員至「主檔資料 → 客戶資料 → 同步舊系統客戶」，閱讀範圍後按「同步最新資料」。來源為 LEGACY_DATABASE_URL 指向的舊庫；若該庫是備份，請先自行更新備份。

更新欄位：既有轉入客戶的名稱、聯絡人、電話、手機、統編、常用備註；地址的名稱、文字與聯絡資訊。新增客戶使用舊庫結帳方式及現金發票設定。現有客戶的結帳設定、區域與公司、LINE 綁定、巡查、樓層、帳務及桶數均保留。新增客戶的餘額與桶數從零開始，期初金額另走上線交接。

保留客戶及地址 ID，不刪除舊庫已消失的記錄。地址文字改變會清除過時定位，需重新定位。同編號但無轉入對照的客戶略過，結果可展開查看原因。編號超過六碼、缺姓名或地址的來源列略過。同步採資料庫交易與鎖定，失敗整批回復；重複執行不新增重複主檔。

部署：API 與後台皆需建置，並重新啟動 API 才有新端點。既有轉入資料庫使用 legacy_id_map；全新資料庫首次同步會建立該對照表。沒有執行正式資料同步。

驗證：在 apps/api 執行 `npx tsx scripts/test-master-sync.ts`，建立獨立 watererp_master_sync_test_* 資料庫。涵蓋新增、重複及同時同步、客戶與地址 ID 保留、既有訂單與帳務逐欄不變、桶數／巡查保留、定位清除、本機客戶保護及錯誤整批回復。加 --ui 可開啟隔離 API 3111／前端 5179 進行畫面操作。

已實際測試確認畫面、同步結果、清單與詳細資料更新。測試資料庫保留以供檢查。
